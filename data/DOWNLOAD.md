# Large assets not stored in this repository

Thirteen files exceed what a git repository should carry (the largest is 897 MB; GitHub
refuses any single file over 100 MB). They are the full-resolution reader-study image
packets and the grading montages — the images the three blinded readers actually saw.

They are available on request from the corresponding author and will be deposited with a
DOI before publication. Everything needed to interpret them — the field manifests, the
blinding keys, the scored reader calls — is in `reader_study/` in this repository.
